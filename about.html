Real-World Applications of Arrays

1. Introduction

An array is a data structure used to store multiple values in a single variable. The values are arranged in an ordered collection and can be accessed using indexes. Arrays are used in online shopping, education, banking, gaming, and data analysis.

2. Real-World Applications of Arrays

E-commerce systems

Arrays organise product information, shopping cart items, and prices.

Educational systems

Arrays can store examination scores and attendance records.

Banking applications

Arrays can hold collections of transaction records for processing.

Gaming applications

Arrays can store player scores, inventory items, and game-board positions.

Data analysis

Arrays can store numerical data for calculating totals and averages.

3. Why Are Arrays Necessary?

  • They group related values under one variable name.
  • They make individual elements accessible by index.
  • Loops can process many values with less repetitive code.
  • They support operations such as searching, adding, and removing elements.
  • They make collections of data easier to manage.

However, some array operations, such as inserting or removing elements in the middle, may require shifting other elements.

4. Selected Application: EasyCart

EasyCart is a Shopping Cart Total Calculator. Users can view sample products and prices, add products to a cart, remove items, clear the cart, and view the total cost.

  • HTML: Structures the webpage.
  • CSS: Controls its appearance.
  • JavaScript: Manages products, the cart, and calculations.

EasyCart is a front-end demonstration. It does not process actual payments or permanently store cart items.

5. How Arrays Are Used in EasyCart

5.1 The products array

const products = [
    { id: 1, name: "T-Shirt", price: 80, icon: "👕" },
    { id: 2, name: "Shoes", price: 200, icon: "👟" },
    { id: 3, name: "Bag", price: 120, icon: "👜" }
];

The products array stores three product objects, each containing an ID, name, price, and icon. It is used to display the available products.

5.2 The cart array

const cart = [];

The cart array begins empty and stores products selected by the user. Items are held in memory while the page is open and are not permanently saved.

5.3 Adding products with push()

cart.push(product);

The push() method adds the selected product to the end of the cart array.

5.4 Finding products with find()

const product = products.find(function(item) {
    return item.id === productId;
});

The find() method searches for the product with the matching ID.

5.5 Calculating the total with forEach()

let total = 0;

cart.forEach(function(item) {
    total += item.price;
});

The forEach() method visits each cart item and adds its price to the total. For example, a T-shirt costing GH₵80 and shoes costing GH₵200 produce a total of GH₵280.

5.6 Removing an item with splice()

cart.splice(index, 1);

The splice() method removes one item from the cart at the specified index.

5.7 Clearing the cart

cart.length = 0;

Setting the array's length to zero removes all its elements.

5.8 Displaying products with forEach()

The displayProducts() function uses products.forEach() to create a product card for each item in the products array.
